# Nexora AI overview

Nexora AI is a modular assistant ecosystem. Its main components are NexoraLM (language-model research), NexoraGPT (chat assistant), Nexora Knowledge (retrieval), Nexora Memory (user-controlled memory), Nexora Agents (bounded workflows), and future specialist interfaces for coding, research, vision, and voice.

The current starter has a FastAPI backend, browser frontend, SQLite persistence, configurable model provider, document ingestion, lexical retrieval, optional embeddings, and a small educational Transformer training script. It is not a fully trained large foundation model.

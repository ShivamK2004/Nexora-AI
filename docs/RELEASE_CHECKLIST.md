# Release Readiness Checklist

## Product
- [ ] All advertised features verified on a clean install.
- [ ] User onboarding and error states reviewed.
- [ ] Accessibility and responsive UI checks completed.
- [ ] Feedback and support route defined.

## Model and data
- [ ] Model card and benchmark report approved.
- [ ] Dataset manifest and license review completed.
- [ ] Evaluation and regression tests pass.
- [ ] Provider data handling approved.

## Security and privacy
- [ ] Authentication and tenant isolation implemented.
- [ ] Security review and penetration test completed.
- [ ] Secrets, encryption, backups, and deletion validated.
- [ ] Privacy notice and terms approved.

## Operations
- [ ] Production deployment configuration reviewed.
- [ ] Monitoring and alerts configured.
- [ ] Load and failure tests pass.
- [ ] Restore and rollback drills completed.
- [ ] On-call and incident response documented.
